# Aura Portfolio

Portfolio personal construido con Vue 3 + Vite.

## 🚀 Stack Tecnológico

- **Vue 3** - Framework JavaScript progresivo
- **Vite** - Build tool de próxima generación
- **Vue Router 4** - Enrutamiento oficial para Vue
- **Vuex 4** - Gestión de estado
- **GSAP 3** - Animaciones de alto rendimiento
- **SCSS** - Preprocesador CSS

## 📦 Instalación

```bash
npm install
```

## 🛠️ Desarrollo

Inicia el servidor de desarrollo en `http://localhost:8080`:

```bash
npm run dev
```

## 🏗️ Construcción

Compila y minifica para producción:

```bash
npm run build
```

## 👀 Vista Previa

Vista previa de la construcción de producción:

```bash
npm run preview
```

## 📝 Notas de Migración

Este proyecto fue migrado de Vue 2 + Vue CLI a Vue 3 + Vite.

### Cambios principales:

- ✅ Vue 3 con Composition API disponible (actualmente usa Options API)
- ✅ Vite para builds ultra-rápidos
- ✅ Vue Router 4
- ✅ Vuex 4
- ✅ GSAP 3.13 (actualizado)
- ✅ Plantillas convertidas de Pug a HTML
- ✅ Dependencias actualizadas

### Estructura del proyecto:

```
portfolio/
├── public/          # Recursos estáticos
├── src/
│   ├── assets/      # Imágenes y recursos
│   ├── mixins/      # Mixins de Vue
│   ├── router/      # Configuración de rutas
│   ├── store/       # Store de Vuex
│   ├── styles/      # Estilos SCSS
│   ├── views/       # Componentes de vista
│   ├── App.vue      # Componente raíz
│   └── main.js      # Punto de entrada
├── index.html       # HTML principal
├── vite.config.js   # Configuración de Vite
└── package.json     # Dependencias
```
